# Student Management System

## Description

This is a simple Python project created for the SEN 401 Software Configuration Management laboratory. The application demonstrates a modular project structure using separate modules for data, helper functions, and the main application.

## Repository

[mayowa-kalejaiye/student-management-system](https://github.com/mayowa-kalejaiye/student-management-system)

## Project Structure

```
student-management-system/
│
├── app.py
├── students.py
├── requirements.txt
├── README.md
│
└── utils/
    └── helpers.py
```

## Files

- **app.py** - Runs the demo application.
- **students.py** - Stores student names and scores.
- **utils/helpers.py** - Contains helper functions for finding the highest and lowest scores.
- **requirements.txt** - Lists project dependencies.
- **README.md** - Project documentation.

## How to Run

```bash
python app.py
```
